# Classic Player Heads

This Bukkit/Spigot plugin adds the well-known feature of player heads that drop. However, very few of these plugins are directly built for Minecraft 1.7.10. I wanted to add an option for players on older versions.

### Features

* Player drops head when killed by player
* "Killed by [player-name]" appears under head name

### Plans

* More versions supported
* Customizable "Killed by" lore/description
